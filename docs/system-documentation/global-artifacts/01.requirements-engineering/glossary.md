# Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**

Column "TEA (PT)" is optional. If the team does not intend to use it, then remove it.

| **_TEA_** (EN)                             | **_TEA_** (PT)                    | **_Description_** (EN)                                                                                                                                                                                              |
|:------------------------------------------|:----------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Acceptance Criterion**                  | **Critério de Aceitação**         | Condition that a software product must satisfy to be accepted by a user or stakeholder.                                                                                                                             |
| **Authentication**                        | **Autenticação**                  | The process of verifying a user's identity before accessing a system.                                                                                                                                               |
| **Backlog**                               | **Backlog**                       | A list of features or tasks that need to be completed in a project, often used in agile methodologies.                                                                                                              |
| **Budget**                                | **Orçamento**                     | In the simulator, the player/user acquires trains within the available budget. This also affects stations, depots, and terminals.                                                                                   |
| **Calculation of Train (de)Acceleration** | **Cálculo da (des)Aceleração**    | The process of figuring out how quickly a train speeds up (acceleration) or slows down (deceleration).                                                                                                              |
| **CamelCase**                             | **CamelCase**                     | A way of writing words where the first letter of each word is capitalized except for the first word.                                                                                                                |
| **Carriage**                              | **Carruagem**                     | Distinguished by the type of cargo it can transport (e.g., passenger, mail, coal, iron ore, steel, car) and has no acquisition cost.                                                                                |
| **Cargo**                                 | **Carga**                         | Good or resource that is transported by train using a carriage.                                                                                                                                                     |
| **City**                                  | **Cidade**                        | Has a name, a location (with XY coordinates on the map), and a set of blocks that represent housing.                                                                                                                |
| **City Tag**                              | **Etiqueta de Cidade**            | A label that would appear on the map if a GUI is considered.                                                                                                                                                        |
| **Collision Detection**                   | **Deteção de Colisão**            | Method used to check if two objects bump into each other.                                                                                                                                                           |
| **Depot**                                 | **Depósito**                      | Facility that supports train operation.                                                                                                                                                                             |
| **DM**                                    | **DM**                            | A conceptual model of the problem domain that describes the objects, their attributes, and the relationships between them, reflecting the real-world entities and processes relevant to the system being developed. |
| **Editing of Line Detail**                | **Edição de Detalhe da Linha**    | Changing the information about a transport route.                                                                                                                                                                   |
| **Editor**                                | **Editor**                        | A person who can create a map and scenario that can be provided in a bundle with the game or sold separately.                                                                                                       |
| **Electrified Line**                      | **Linha Eletrificada**            | A railway track powered by electricity.                                                                                                                                                                             |
| **Functional Requirement**                | **Requisito Funcional**           | Describes what a system should do (e.g., feature)                                                                                                                                                                   |
| **Historical Restriction**                | **Restrição Histórica**           | Historical event that makes sense in the scenario and changes the operating conditions of the simulator.                                                                                                            |
| **JaCoCo**                                | **JaCoCo**                        | A tool for measuring code coverage in Java applications.                                                                                                                                                            |
| **JUnit**                                 | **JUnit**                         | A framework for unit testing in Java.                                                                                                                                                                               |
| **Locomotive**                            | **Locomotiva**                    | Provides traction to the composition (train) and can be of different types, namely, run by steam, diesel, and electricity.                                                                                          |
| **Mixed Industry**                        | **Indústria Mista**               | A port that can import or export any cargo, depending on the scenario settings.                                                                                                                                     |
| **MVP**                                   | **MVP**                           | Minimum Viable Product.                                                                                                                                                                                             |
| **N/A**                                   | **N/A**                           | Used when a field or condition does not apply to a specific situation.                                                                                                                                              |
| **Non-functional Requirement**            | **Requisito Não-funcional**       | Criterion that defines how a system should behave, rather than what it is supposed to do.                                                                                                                           |
| **OO**                                    | **OO**                            | Object-Oriented Programming.                                                                                                                                                                                        |
| **Plate Number**                          | **Matrícula**                     | A unique identification assigned to each locomotive (e.g., visible at the front of the train).                                                                                                                      |
| **Player**                                | **Jogador**                       | A person who wants to play a game.                                                                                                                                                                                  |
| **Primary Sector Industry**               | **Indústria do Setor Primário**   | Industry that generates resources, such as mine (e.g., iron, coal, bauxite, or nitrate mine) and farm (vegetable, cereal, wool, coffee, rubber, cattle).                                                            |
| **Product Owner**                         | **Responsável pelo Produto**      | The person representing the organization that intends to develop the game.                                                                                                                                          |
| **Railway**                               | **Ferrovia**                      | An efficient, safe, and environmentally friendly way of moving people and goods.                                                                                                                                    |
| **Railway Line**                          | **Linha de Ferrovia**             | Allows the connection of two stations.                                                                                                                                                                              |
| **Requirement Engineering**               | **Engenharia de Requisitos**      | The process of defining, documenting, and maintaining software requirements.                                                                                                                                        |
| **Route**                                 | **Rota**                          | A list of stations where the train passes, along which it loads (carriages) cargo at each station.                                                                                                                  |
| **Scenario Editor**                       | **Editor de Cenário**             | A tool that allows the editor to define restriction and condition for a map.                                                                                                                                        |
| **SCRUM**                                 | **SCRUM**                         | An agile methodology used for project management.                                                                                                                                                                   |
| **Simulation Tool**                       | **Ferramenta de Simulação**       | A system that lets the user define and interact with a railway network.                                                                                                                                             |
| **Simulator**                             | **Simulador**                     | A system or program that mimics a real-world process to help with training, testing, or analysis without real-world risks.                                                                                          |
| **Sprint**                                | **Sprint**                        | A short, time-boxed period to complete a set of tasks in SCRUM.                                                                                                                                                     |
| **SSD**                                   | **SSD**                           | System Sequence Diagram – shows interactions between actor and system in sequence.                                                                                                                                  |
| **Station**                               | **Estação**                       | Facility that supports train operation.                                                                                                                                                                             |
| **SVG Format**                            | **Formato SVG**                   | A scalable vector graphics format used for image and diagram.                                                                                                                                                       |
| **TBD**                                   | **TBD**                           | To be determined. Used for item or specification that is yet to be defined.                                                                                                                                         |
| **TDD**                                   | **TDD**                           | Test-Driven Development.                                                                                                                                                                                            |
| **Technological Restriction**             | **Restrição Tecnológica**         | Limit on which locomotive, industry, or other technology can be used in the game.                                                                                                                                   |
| **Terminal**                              | **Terminal**                      | Facility that supports train operation.                                                                                                                                                                             |
| **Time Restriction**                      | **Restrição de Tempo**            | The period in which the simulation will take place.                                                                                                                                                                 |
| **Timetable Generation/Management**       | **Gestão de Horário**             | The process of creating and organizing schedule.                                                                                                                                                                    |
| **Train**                                 | **Comboio**                       | A vehicle composed of locomotive and carriage.                                                                                                                                                                      |
| **Transforming Industry**                 | **Indústria de Transformação**    | Transforms the resource provided by the Primary Sector Industry into a new product.                                                                                                                                 |
| **UC**                                    | **UC**                            | Use Case: A description of a system’s behavior in response to external requests, usually from an actor, to achieve a goal.                                                                                          |
| **UCD**                                   | **UCD**                           | Use Case Diagram – A diagram that shows the interactions between a system and its actors, focusing on the sequence of messages exchanged during a specific use case or scenario.                                    |
| **Upgrade**                               | **Melhoria**                      | Improvement to the quality of something (a station for example).                                                                                                                                                    |
| **US**                                    | **US**                            | User Story: a short description of a feature from the user’s perspective that captures what they want and why.                                                                                                      |
