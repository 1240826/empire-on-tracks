# Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**

Column "TEA (PT)" is optional. If the team does not intend to use it, then remove it.

| **_TEA_** (EN)                             | **_TEA_** (PT)                  | **_Description_** (EN)                                                                                                                                        |
|:-------------------------------------------|:--------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Authentication**                         | **Autenticação**                | The process of verifying a user's identity before accessing a system.                                                                                         |
| **Budget**                                 | **Orçamento**                   | In the simulator, the player/user acquires trains within the available budget. This also affects stations, depots, and terminals.                             |
| **Calculation of Train (de)Accelerations** | **Cálculo da (des)Aceleração**  | Calculation of train (de)accelerations is the process of figuring out how quickly a train speeds up (acceleration) or slows down (deceleration).              |
| **CamelCase**                              | **CamelCase**                   | CamelCase is a way of writing words where the first letter of each word is capitalized except for the first word.                                             |
| **Carriage**                               | **Carruagem**                   | A carriage is distinguished by the type of cargo it can transport (e.g., passengers, mail, coal, iron ore, steel, cars) and has no acquisition cost.          |
| **Cargo**                                  | **Carga**                       | Cargo represents the goods or resources that are transported by trains using carriages.                                                                       |
| **City**                                   | **Cidade**                      | A city bears a name, a location (with XY coordinates on the map), and a set of blocks that represent housing.                                                 |
| **City Tag**                               | **Etiqueta de Cidade**          | A label that would appear in the map if a GUI is considered.                                                                                                  |
| **Collision Detection**                    | **Deteção de Colisão**          | Collision detection is the method used to check if two objects bump into each other.                                                                          |
| **Depot**                                  | **Depósito**                    | Depot is a facility that supports train operations.                                                                                                           |
| **Editing of Line Details**                | **Edição de Detalhes da Linha** | Editing of line details means changing the information about a transport route.                                                                               |
| **Editor**                                 | **Editor**                      | An editor is a person who can create maps and scenarios that can be provided in a bundle with the game or sold separately.                                    |
| **Electrified Line**                       | **Linha Eletrificada**          | A railway track powered by electricity.                                                                                                                       |
| **Historical Restriction**                 | **Restrição Histórica**         | Historical event that makes sense in the scenario and changes the operating conditions of the simulator.                                                      |
| **JaCoCo**                                 | **JaCoCo**                      | A tool for measuring code coverage in Java applications.                                                                                                      |
| **JUnit**                                  | **JUnit**                       | A framework for unit testing in Java.                                                                                                                         |
| **Locomotive**                             | **Locomotiva**                  | A locomotive provides traction to the composition (train) and can be of different types, namely, run by steam, diesel, and electricity.                       |
| **Mixed industry**                         | **Indústria mista**             | A port can import or export any cargo, depending on the scenario settings.                                                                                    |
| **MVP**                                    | **MVP**                         | Minimal Viable Product.                                                                                                                                       |
| **Non-functional Requirement**             | **Requisito Não-funcional**     | Criteria that define how a system should behave, rather than what it is supposed to do.                                                                       |
| **OO**                                     | **OO**                          | Object-Oriented Programming.                                                                                                                                  |
| **Plate Number**                           | **Matrícula**                   | A unique identification assigned to each locomotive (e.g., visible at the front of the train).                                                                |
| **Player**                                 | **Jogador**                     | A player is a person who wants to play a game.                                                                                                                |
| **Primary sector Industry**                | **Indústria do Setor Primário** | Industry that generates resources, such as mines (e.g., iron, coal, bauxite, or nitrate mines) and farms (vegetables, cereals, wool, coffee, rubber, cattle). |
| **Product Owner**                          | **Responsável pelo Produto**    | The person representing the organization that intends to develop the game.                                                                                    |
| **Railway**                                | **Ferrovia**                    | The railway is an efficient, safe, and environmentally friendly way of moving people and goods.                                                               |
| **Railway Line**                           | **Linha de Ferrovia**           | A railway line allows the connection of two stations.                                                                                                         |
| **Route**                                  | **Rota**                        | A route is a list of stations where the train passes, along which it loads (carriages) cargo at each station.                                                 |
| **Scenario Editor**                        | **Editor de Cenários**          | A tool that allows editors to define restrictions and conditions for a map.                                                                                   |
| **SCRUM**                                  | **SCRUM**                       | An agile methodology used for project management.                                                                                                             |
| **Simulation Tool**                        | **Ferramenta de Simulação**     | A system that lets users define and interact with a railway network.                                                                                          |
| **Simulator**                              | **Simulador**                   | A simulator is a system or program that mimics real-world processes to help with training, testing, or analysis without real-world risks.                     |
| **Sprint**                                 | **Sprint**                      | A sprint is a short, time-boxed period to complete a set of tasks in SCRUM.                                                                                   |
| **Station**                                | **Estação**                     | Stations are facilities that support train operations.                                                                                                        |
| **SVG Format**                             | **Formato SVG**                 | A scalable vector graphics format used for images and diagrams.                                                                                               |
| **TBD**                                    | **TBD**                         | To be determined. Used for items or specifications that are yet to be defined.                                                                                |
| **TDD**                                    | **TDD**                         | Test-Driven Development.                                                                                                                                      |
| **Technological Restriction**              | **Restrição Tecnológica**       | Limit on which locomotives, industries, or other technologies can be used in the game.                                                                        |
| **Terminal**                               | **Terminal**                    | Terminals are facilities that support train operations.                                                                                                       |
| **Time Restriction**                       | **Restrição de Tempo**          | The period in which the simulation will take place.                                                                                                           |
| **Timetable Generation/Management**        | **Gestão de Horários**          | Timetable generation/management is the process of creating and organizing schedules.                                                                          |
| **Train**                                  | **Comboio**                     | A train is a vehicle composed of locomotives and carriages.                                                                                                   |
| **Transforming Industry**                  | **Indústria de Transformação**  | Transforms the resources provided by the Primary Sector Industries into new products.                                                                         |
| **Upgrade**                                | **Melhoria**                    | Improvement to the quality of something.                                                                                                                      |
| **US**                                     | **US**                          | User Story.                                                                                                                                                   |
